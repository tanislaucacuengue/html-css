# HTML & CSS — Caderno de aprendizagem

Repositório pessoal de exercícios e desafios práticos de HTML5 e CSS3, desenvolvidos por **Benjamim Tanislau José Cacuengue** durante um percurso contínuo de aprendizagem com base no curso de HTML e CSS de **Gustavo Guanabara**.

> Este repositório está em desenvolvimento. Estou a concluir o módulo 3; os módulos 4 e 5 e novos exercícios serão acrescentados progressivamente. O conteúdo actual não representa o curso completo.

## Organização

- `desafio/` reúne desafios e pequenos projectos práticos.
- `exercícios/` reúne exercícios de HTML e CSS, organizados por pasta e número.
- `multi_midia/` contém imagens e vídeos de apoio.
- `pdf/` contém materiais PDF de consulta.
- `index.html` serve de catálogo visual para os caminhos existentes nesta versão.

As pastas e páginas são mantidas nos seus caminhos actuais. O índice usa ligações relativas para preservar a navegação sem reorganizar os exercícios.

## Como consultar

Abre `index.html` num navegador e escolhe o exercício ou material. O filtro e as animações suaves usam JavaScript nativo; sem JavaScript, as ligações continuam disponíveis. O repositório não declara um comando de compilação ou de arranque de servidor, por isso este README não inventa um procedimento desses.
